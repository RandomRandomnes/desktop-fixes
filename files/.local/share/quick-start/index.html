Phoenix quick start

Installing and using Phoenix, a Windows-style desktop for Arch Linux. It is a custom version of illogical-impulse, not the official project. Installation takes about 15 minutes; the setup assistant follows at the first start.

Requirements

  • A USB stick of 16 GB or more. It is erased.
  • A 64-bit PC that starts in UEFI mode.
  • A disk to erase, or 40 GB of unallocated space next to Windows (shrink a partition in Windows Disk Management first).
  • Internet during the first start, for applications and updates. Installing works offline.

Back up first. "Erase" deletes everything on the selected disk. "Use free space" leaves existing partitions untouched.

Write the USB stick

OnTool
WindowsRufus: select DD Image mode when asked. Or balenaEtcher.
MacbalenaEtcher
LinuxKDE ISO Image Writer, balenaEtcher, or dd:
lsblk # find the stick, e.g. sdc sudo dd if=phoenix-<date>.iso of=/dev/sdX bs=4M status=progress oflag=sync

Start from the stick

  1. Open the firmware settings (Del or F2 at power-on). Set the boot mode to UEFI and turn Secure Boot off.
    For Secure Boot on the new system: put Secure Boot in Setup Mode (clear the keys) instead. The installer then creates and enrolls keys.
  2. Insert the stick, restart, open the one-time boot menu and select the stick.

Install

The stick starts to a text prompt. Run:

install-phoenix

Nothing is written to disk until YES is entered.

  1. Disk: the USB stick itself is never listed. Disks are tagged [Windows], [Linux] or [empty]. On a disk with partitions, choose 1 erase or 2 use free space.
  2. Username (lowercase letters, digits, -, _), password and computer name. The password is also the administrator password.
  3. Log in automatically? Yes skips the password at startup; the lock screen still uses it.
  4. Encrypt the disk? Yes asks for a passphrase at every startup, until TPM unlock is set up (Extras).
  5. Secure Boot keys: asked only when the firmware is in Setup Mode.
  6. Check the summary, enter YES. Copying takes 5 to 10 minutes.
  7. Remove the stick and run reboot. If keys were created, turn Secure Boot on in the firmware after the first successful start.

The new system has the Default appearance and only Firefox. It starts directly, without a boot menu (see Boot menu and Windows).

Windows float and have a title bar: red closes, green maximizes (or double-click the title bar), yellow minimizes to the dock; click the dock icon to restore. For tiling instead, turn off Windows-style windows in Settings › Extras.

Settings

Super + I. Laid out like Windows Settings: System, Bluetooth & devices, Network, Personalization, Apps, Update, Extras.

Extras

One switch per added feature; off restores the standard illogical-impulse behavior: Windows-style windows, minimize to dock, app grid, live system graphs (CPU, GPU, RAM), Wallpaper Engine, the KDE switch and more.

Setup profiles

A profile is one file with an appearance and a set of feature switches. Built in: Default (Windows-style, monochrome). More, such as Custom_01, are on the project page.

  • Apply: Settings › Extras › Use a profile file. Current settings are backed up first.
  • Save your own: Settings › Extras › Share my setup.
  • A profile never changes the dock or the app grid, and never turns on Wallpaper Engine.

Updates

The taskbar's update button shows how many updates are waiting. One click installs, in this order, system updates, the illogical-impulse shell, system fixes and, if enabled, custom fixes; the password is asked once. Settings › Update shows what is installed.

  • System fixes repair problems caused by Arch, Hyprland or illogical-impulse updates. They are always installed, right after the update they belong to, and only on systems with matching versions. A fix that has to change a custom file uses the variant made for the installed custom version; if none fits, the file is left unchanged and Settings › Update says to install the latest custom fixes.
  • Custom fixes (1.1, 1.11, …) repair the custom features (hypr-guard, Wallpaper Engine, Settings, the setup assistant). Optional, chosen in the setup assistant. Revert the last one: Settings › Update › Undo last; it is not reinstalled until a newer fix is published.
  • Major custom versions (2, 3, …) never install by themselves. Settings › Update explains the changes and the risk, and upgrades only on confirmation.
  • After an update that breaks the desktop: Settings › Update › Run health check.

Boot menu and Windows

The system starts Arch Linux directly, without a menu. Windows stays installed and starts from the firmware's one-time boot menu (keys).

To get a menu at every start: setup assistant › Drivers and updates › Startup, or in a terminal:

boot-loader use refind # graphical menu, finds Windows on any disk boot-loader use systemd-boot # simple menu; lists Windows only on the same EFI partition boot-loader use grub # text menu; only with Secure Boot off boot-loader use direct # back to no menu

Switching only changes which loader the firmware starts first; nothing is deleted.

Extras

Wallpaper Engine

Needs Steam and Wallpaper Engine (bought on Steam). Install both, then turn on Settings › Extras › Wallpaper Engine background. A picker appears in the right sidebar. It is off by default.

KDE Plasma

Installed alongside. Turn on the KDE switch in Settings › Extras, then switch from the right sidebar or the power menu.

Unlock an encrypted disk with the TPM

~/WELCOME-phoenix.txt lists the two commands. Afterwards the passphrase is only needed if the firmware or Secure Boot state changes.
