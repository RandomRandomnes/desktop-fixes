Quick start

How to install this desktop on a computer and use it. Installation takes about 15 minutes, followed by a few minutes of setup at the first start.

What you need

  • A USB stick of 16 GB or more. Everything on it is erased.
  • A 64-bit PC that starts in UEFI mode (almost every PC from the last ten years).
  • Either a whole disk that can be erased, or 40 GB of free, unallocated space next to Windows.
  • An internet connection for applications and updates during setup. The installation itself works offline.

Back up important data first. "Erase" deletes everything on the selected disk. The "use free space" option leaves existing partitions unchanged.

Make the USB

Write the file arch-clone-<date>.iso to the USB stick with one of the following tools:

OnUse
WindowsRufus (when prompted, select Write in DD Image mode) or balenaEtcher
MacbalenaEtcher
LinuxKDE ISO Image Writer, balenaEtcher, or the command below

On Linux, identify the stick with lsblk (for example sdc), then run:

sudo dd if=arch-clone-<date>.iso of=/dev/sdX bs=4M status=progress oflag=sync

Start from the USB

  1. Open the PC's firmware settings (BIOS): usually Del or F2 right after switching on. Make sure the boot mode is UEFI and Secure Boot is off.
    To use Secure Boot, select "Setup Mode" (clear the keys) instead; the installer then creates new keys. This requires a TPM chip.
  2. Insert the stick, restart and open the one-time boot menu. Select the USB stick.

Install

The stick starts to a text screen. Enter the following command:

install-clone

The installer asks a few questions and makes no changes until YES is entered at the end:

  1. Disk, and whether to erase it or use free space next to Windows. Windows is detected automatically and receives its own boot menu entry.
  2. Username, password and computer name.
  3. Log in automatically? If yes, no password is requested at startup.
  4. Encrypt the disk? If yes, a passphrase is required at every startup (until TPM unlock is configured, see Extras).
  5. Review the summary and enter YES. Installation takes 5 to 10 minutes.
  6. Remove the stick and enter reboot. If Secure Boot keys were created, enable Secure Boot in the BIOS again.

The new system starts with the Default appearance and no applications other than Firefox. Further applications are selected at the first start. It starts directly, without a boot menu; a boot menu (GRUB, systemd-boot or rEFInd) can be added in the setup assistant under Drivers and updates › Startup.

Windows

Windows float as on Windows and have a title bar: red closes, green maximizes, yellow minimizes to the dock. Clicking the application in the dock restores it. Double-clicking a title bar maximizes the window.

Settings

Super + I. Extras contains a switch for each additional feature (Windows-style windows, Wallpaper Engine, live system graphs, the KDE switch and more), plus Use a profile file, Share my setup and Run the first-time setup again.

Updates

The update button on the taskbar shows the number of pending updates. One click updates the system, the desktop and, if enabled, the custom bug fixes. The administrator password is requested once.

  • Bug fixes (versions such as 1.1 or 1.12) are installed with regular updates.
  • New major versions (2, 3 and later) are never installed automatically. Settings › Update describes the changes, warns that they may alter or break parts of the current setup, and upgrades only after confirmation.
  • To revert the most recent bug fix: Settings › Update › Undo last.

Extras

Wallpaper Engine

Animated wallpapers require Steam and Wallpaper Engine (purchased on Steam). Install Steam from the setup assistant or the Gaming bundle, install Wallpaper Engine, then enable Settings › Extras › Wallpaper Engine background. A wallpaper picker appears in the right sidebar.

Switch to KDE Plasma

The KDE Plasma desktop is also installed. Enable the KDE switch in Settings › Extras to use it from the right sidebar or the power menu.

Unlocking an encrypted disk automatically

The file WELCOME-clone.txt in the home folder lists the two commands that allow the TPM chip to unlock the disk at startup.

Sharing a setup

Settings › Extras › Share my setup saves the appearance, features and application list to one file. It can be applied in the setup assistant or with Use a profile file.

Troubleshooting

ProblemTry
The USB stick does not startTurn Secure Boot off and set the boot mode to UEFI. Rewrite the stick (Rufus: DD Image mode).
Black screen after installationUsually caused by an NVIDIA card. Press Ctrl + Alt + F2, log in, run sudo pacman -S nvidia-open-dkms nvidia-utils, then reboot.
Starting Windows or another systemOpen the firmware's one-time boot menu at power-on (see the key table above), or add a boot menu: setup assistant › Drivers and updates › Startup, or boot-loader use refind in a terminal.
Text and elements are too small or too largeSettings › System › Display › Scale.
No Wi-FiRight sidebar (Super + N) › Wi-Fi.
The desktop misbehaves after an updateSettings › Update › Run health check, or Undo last for a bug fix.
Running the setup assistant againSettings › Extras › Run the first-time setup again.
